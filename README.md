# 세종 이슈 대시보드

https://ysong86.github.io/ — 세종연구원이 공공데이터로 세종의 현안을 살피는 상황판 네 가지를 한곳에서 봅니다.

| 상황판 | 주소 | 공개 |
|---|---|---|
| 세종 생활권 재구조화 상황판 | /zone_sejong/ | 비밀번호 |
| 세종 행복도시 상가공실 상황판 | /vacant_sejong/ | 비밀번호 |
| 세종시 물환경 상황판 | /water_sejong/ | 공개 |
| 세종시 교통안전 상황판 | /traffic_sejong/ | 공개 |

카드를 누르면 같은 화면 안(iframe)에서 열리고 위쪽 탭으로 오갑니다(`#/vacant` 처럼 주소로 바로 열 수도 있음).
미리보기 그림은 `python tools/make_thumbs.py` 로 다시 만든다(공개 상황판은 캡처, 비밀번호 상황판은 수치를 흐린 미리보기 영상의 한 장면).
